# 已知限制

- 本项目不访问 X 生产环境；阶段 A 的浏览器验证仅使用本地模拟 X 页面。页面结构变化仍可能需要更新解析器。
- 按用户决定，不再测试 AdsPower。既有 A-10 实现和历史契约证据保留，但它不属于当前发布门禁，也不声明真实环境可用。
- 当前使用 SQLite，API 与 worker 必须共享同一可靠本地数据卷；不支持多主机并发写入。
- Direct Chrome profile 含登录状态，应视为敏感数据，必须限制文件权限并纳入加密备份策略。
- 5 万 followers 加 5 万 following 的基线是阶段 A 容量目标，不代表无上限扩展承诺。
- artifact 有过期和删除元数据，但物理清理仍需由部署方安排周期任务。
- 绑定身份识别只接受 X `Viewer` 响应的明确结构并 fail closed；X 调整该只读响应时需要更新固定夹具和解析器。当前没有访问 X 生产环境验证该结构。
